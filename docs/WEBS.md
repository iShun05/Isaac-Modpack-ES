# Webs para encontrar mods y ayuda (Isaac Repentance+)

Comprobadas el 2026-10-09 (responden). Las marcadas con * bloquean descargas automáticas y solo abren en el navegador.

## Dónde conseguir mods
| Web | Para qué |
|---|---|
| [Steam Workshop de Isaac](https://steamcommunity.com/app/250900/workshop/) | Fuente principal: suscripción con un clic y actualización automática. Ordena por «Más reciente» o «Tendencia». |
| [itch.io · mods de Isaac](https://itch.io/game-mods/tag-binding-of-isaac) | Mods fuera de Workshop, skins y proyectos pequeños. |
| [GameBanana](https://gamebanana.com/games/) | Skins y packs gráficos (busca «Binding of Isaac» dentro). |
| [Modding of Isaac](https://www.moddingofisaac.com) | Archivo histórico; sobre todo mods de Rebirth/Afterbirth, poco para Repentance+. |
| [GitHub: etiqueta binding-of-isaac](https://github.com/topics/binding-of-isaac) | Mods en código abierto y herramientas (ej. los mods de PixelPlz). Descarga desde *Releases* o *Code → ZIP*. |

## Herramientas de mods
| Herramienta | Qué hace |
|---|---|
| [REPENTOGON](https://repentogon.com/) · [GitHub](https://github.com/TeamREPENTOGON/REPENTOGON/releases) | Amplía la API de Lua (necesario para mods modernos). Instalación: [repentogon.com/install](https://repentogon.com/install.html). |
| [External Item Descriptions](https://github.com/wofsauge/External-Item-Descriptions/releases) | Descripciones de objetos; ya trae español. Se actualiza solo por Workshop. |
| [Cartridge](https://github.com/TeamHY/cartridge) | Utilidad de presets/guardados de mods (versión 4.33.1 a 2026-10-05). No probada aquí. |
| [Bookworm](https://github.com/catinsurance/bookworm) | Gestor de mods y modpacks (última versión 2025-04). No probada aquí. |
