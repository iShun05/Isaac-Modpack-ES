Detalle de cada mod en [MODS.md](MODS.md). Perfil «clean» = esenciales + recomendados + opcionales; se apagan los trucos, los caprichos y los duplicados.

## 2. Pasa a «clean» (se desactivan con `perfil clean`, reversible)
- **Trucos:** Da Rules, InvEdit (+Cursor Trigger), NO CURSES, GoodTrip. Útiles para probar, quitan el desafío en partidas serias.
- **Caprichos:** Miku baila, personajes que maúllan, Neko alt Judas, Alice/Teto/Falin/Schrödinger/Squigly, POG y Specialist, Garry's Mod, Slime Rancher, energypills.
- Varios caprichos **reescriben `players.xml`** de un mismo personaje (Eve, Judas, Azazel, T. Lazarus, T. Bethany): activos a la vez pueden pisarse.

## 3. Núcleo recomendado (siempre activo)
EID · Custom Stage API · miniMAPI · Stats+ · Improved Chargebars · Enhanced Boss Bars · Boss Rush Wave Counter · Better Character Menu · Colored Achievement Descriptions · Lemegeton Wisp List · Ready to Fire · Visible Challenge Unlocks · Echo Chamber Guide · No Costumes · Rocas con «?» · Watch out, laser! · No Jam · Angels Drop Items · Samson Berserk Meter · Greed Mode Improved · sinergias (A Pony, Dr. Fetus, Mom's Knife, Spirit Sword) · Unique Birthrights.

## 4. Decisiones tuyas (cambian el juego, no son «limpias» ni «sucias»)
Less Fair Options · Treasure Room Start · Runs Continue Past Mother · Steal From Shops · TimeMachine · Devil Keys · Donation Machine en pisos finales · Never Breakfast · Regret Pedestals · Doblaje al Latino (el resto del juego queda en español de España).
